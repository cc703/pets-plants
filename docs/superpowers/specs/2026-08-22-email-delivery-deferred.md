# 邮件服务配置延期记录

日期：2026-08-22
决策：暂缓外部邮件服务配置，优先完成不依赖发信服务的功能需求与本地验证。

## 当前状态

- 邮箱注册字段已接入。
- 邮箱 + 密码登录已接入。
- 用户名 + 密码登录保持兼容。
- 邮箱唯一性约束已记录在 `server/migrations/007_email_identity.sql`。
- 服务端暂未配置 SMTP/API 邮件服务商。
- 注册激活邮件、邮箱真实性验证、邮箱验证码登录暂不作为当前阶段完成条件。

## 延期原因

邮件能力依赖外部服务商、发件域名、SMTP/API 凭据和 SPF/DKIM/DMARC 配置。当前先验证核心业务闭环，避免在外部基础设施未确定时引入不可重复的集成问题。

## 恢复实施条件

- 确定服务商和发件域名。
- 获取服务器环境变量配置权限。
- 配置正式 `APP_PUBLIC_URL`。
- 完成 DNS 发信认证。
- 确定激活链接、验证码有效期、发送频率和失败重试策略。

## 恢复时的实施顺序

1. 邮件发送服务和本地 Mailpit/测试收件箱。
2. 注册激活 Token 表和验证接口。
3. 登录对未验证邮箱的状态限制。
4. 邮箱验证码发送、校验、过期和限流。
5. 前端激活结果页、验证码登录模式和错误状态。
6. 生产服务器配置后执行完整回归。

## 验收边界

在邮件服务配置完成前，不能声称“邮箱真实性验证已完成”“激活邮件已完成”或“邮箱验证码登录已完成”。当前只声称邮箱字段注册和邮箱密码登录已完成。
